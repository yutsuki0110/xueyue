# 雪月地图图标资源包 v0.1

这是一套可直接用于「雪月地图悬浮窗」的 2.5D 风格 WebP 图标包。

## 用法

1. 将 `icons/` 里的 `.webp` 文件上传到 GitHub 仓库或 CDN。
2. 推荐路径类似：

```txt
https://cdn.jsdelivr.net/gh/<user>/<repo>@latest/map-icons
```

3. 在地图脚本设置页中，将「图标资源包 CDN」填为该路径。
4. 地点可以使用 `iconKey` / `terrain` 自动匹配图标，也可以单独填写 `iconUrl`。
